# SAP TEAM Discord Bot

بوت ديسكورد بأمر واحد فقط:

```text
/بحث-سكربتات
```

يحاول البوت ضبط اسم العرض داخل كل سيرفر إلى **𝑺𝑨𝑷 𝑻𝑬𝑨𝑴** عند التشغيل. يحتاج ذلك إلى صلاحية **Manage Nicknames**؛ اسم مستخدم Discord الأساسي له قيود مختلفة عن اسم العرض.

## طريقة الاستخدام

- المشرف يستخدم الأمر **بدون اسم ماب** لتفعيل أو تعطيل البحث في الروم الحالي فقط.
- بعد التفعيل، أي عضو داخل نفس الروم يستخدم الأمر مع اسم الماب، مثل:
  `/بحث-سكربتات ماب: MM2`
- يعرض البوت أفضل نتيجة عامة من ScriptBlox، مع اسم السكربت، اسم الماب، صورة اللعبة، ومعاينة الكود.
- زر **نسخ السكربت** يفتح الكود برسالة خاصة للعضو. Discord لا يسمح للبوت بالنسخ المباشر إلى حافظة جهاز المستخدم، لذلك يتم نسخه يدويًا من الرسالة الخاصة.
- السكربتات الطويلة تُرفق كملفات `.lua` عند الضغط على زر النسخ.

اسم الأمر التقني هو `search-scripts` لأن Discord يفرض قيودًا على أسماء أوامر slash، وتظهر ترجمته العربية `بحث-سكربتات` للمستخدم العربي.

## التشغيل

1. ثبّت الاعتمادات: `npm install`
2. أضف `DISCORD_BOT_TOKEN` إلى Replit Secrets.
3. اختياريًا أضف `DISCORD_GUILD_ID` للاختبار الفوري داخل سيرفر واحد.
4. شغّل `npm run dev` أو ابنِ ثم شغّل `npm run build && npm start`.

البوت يعرض محتوى المصدر العام فقط ولا يشغّل أي سكربت داخل البوت.
